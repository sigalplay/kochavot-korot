# כוכבות קוראות
משחק הכנה לכיתה א׳: לומדים אותיות וצלילים, ובכל אות מרוויחים פריט שהכוכבת לובשת.

## הפעלה
מפעילים שרת מקומי (למשל `npx http-server`) ופותחים את `index.html`. המשחק מותאם לטאבלט לרוחב, ומתאים את עצמו לכל מסך.

## מבנה
- `index.html`: המשחק.
- `js/content.js`: **כל התוכן**: אותיות, מילים, פריטים, מיקומים על הכוכבת, מסלולי כתיבה ומשפטי הקול. מחליפים כאן איורים.
- `js/game.js`: המנוע (מסכים, פעילויות, חדר הלבשה, כתיבה מודרכת).
- `js/audio.js`: קול (הקלטה, ואם אין, קובץ, ואם אין, קול ממוחשב) וצלילי משוב.
- `studio.html`: אולפן הקלטות. מקליטים את ההוראות בקול שלכם, ישירות בטאבלט.
- `worksheets/letter-worksheet.html?l=נ`: דף עבודה להדפסה לכל אות.
- `docs/art-brief.md`: מפרט האיורים הסופיים.
- `docs/recording-script.md`: כל המשפטים להקלטה.

## יחידת אות (5 שלבים)
1. צליל פותח: איזה פריט מתחיל בצליל.
2. אוצר מילים: עוד 3 תמונות מתוך 6.
3. זיהוי האות: 5 מופעים בין 10 אותיות דומות.
4. כתיבה בדפוס: סיבוב מודרך עם כוכב, מספרים וחצים, ואז סיבוב לבד.
5. פרס: הפריט עף אל הכוכבת ונשאר עליה בכל המסכים.

אחרי שתי טעויות מופיע רמז מנצנץ. כל ההתקדמות נשמרת במכשיר.

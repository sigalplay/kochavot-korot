# תסריט הקלטות — כוכבות קוראות

**הדרך הקלה:** לפתוח את studio.html בטאבלט ולהקליט שם. ההקלטות נשמרות במכשיר ונכנסות מיד למשחק.

**הדרך השנייה:** להקליט קבצים, לקרוא לכל קובץ בשם שבעמודה הראשונה (למשל open-mem.mp3), לשים בתיקייה audio/ ולהוסיף את שמות הקבצים לרשימה ב-audio/manifest.json.

**טיפים:** לדבר לאט, בחיוך, כמו כוכבת שמדברת עם ילדה. בצלילים (למשל „מְ”) אומרים רק את הצליל הקצר, בלי שם האות.

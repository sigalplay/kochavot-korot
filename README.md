# kochavot-korot
משחק ללימוד אותיות באמצעות בניית מלתחה והלבשת כוכבת קיי־פופ

## איך פותחים
פותחים את `mamlakhat-haotiyot-prototype.html` בדפדפן (מומלץ דרך שרת מקומי, למשל `npx http-server`).

## עולם הלבוש (קבוצה 1) — מ, ש, ל, נ, ס, צ, ח
כל יחידה בנויה מחמישה שלבים קבועים:
1. **צליל פותח** — בוחרים בארון את הפריט שמתחיל בצליל (לחיצה ישירה על האיור).
2. **עוד מילים** — מסמנים שלוש תמונות מתוך שש בלוח (סדר אקראי בכל פעם).
3. **זיהוי האות** — מוצאים 5 מופעים של האות בין 10 אותיות דומות; כל אות עפה לעיגול.
4. **כתיבה בדפוס** — עוברים על האות; ממשיכים רק כשרוב האות כוסה.
5. **סיום** — הפריט עף לתא שלו בארון, ויש דף פעילות להדפסה.

חדר ההלבשה: לכל אחד משבעת הפריטים יש תא בארון. גוררים אל הכוכבת, והמיקום נשמר במכשיר.

## קבצים
- `assets/group1-*.png|jpg` — רקעים משותפים (ארון, לוח מילים ריק, עיגולי איסוף, לוח כתיבה).
- `assets/item-*.svg|png` — הפריטים (מעיל, שעון, לב, נעליים, סיכה, צמיד, חצאית).
- `assets/words/` — תמונות המילים.
- `tools/make-svg-art.py` — מייצר מחדש את איורי ה־SVG.
- `worksheets/letter-worksheet.html?l=נ` — דף פעילות לכל אות.
